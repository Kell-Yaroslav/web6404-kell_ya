## Лабораторная работа №2

**Тема:** Многостраничный сайт «TradeDiary — календарь трейдера»


### Что реализовано

Разработан многостраничный сайт **TradeDiary** — веб-приложение для трейдеров, которое помогает вести дневник сделок и наглядно видеть свою торговлю в виде календаря.

**Страницы сайта (4 шт.):**
- `index.html` — календарь профита по дням месяца с цветовой индикацией;
- `trades.html` — дневник сделок с таблицей и скриншотом графика;
- `news.html` — лента важных мировых и крипто-новостей;
- `about.html` — информация о проекте и об авторе.

### Требования к HTML — выполнено

- **Количество страниц:** 4 .
- **Блочные элементы:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<div>`, `<table>`, `<ul>`, `<h1>`, `<h2>`, `<p>`.
- **Строчные элементы:** `<a>`, `<span>`, `<strong>`, `<em>`, `<img>`.
- **Ссылки:** навигация между 4 страницами + внешняя ссылка на источник новостей.
- **Картинки:** логотип в шапке каждой страницы и скриншот сделки в дневнике.
- **Таблицы:** календарь на главной странице и таблица сделок на странице сделок.

### Требования к CSS — выполнено

- **Внешний подключаемый файл:** `lab2/css/style.css`, подключается через `<link rel="stylesheet" href="css/style.css">`.
- **Использовано 4+ вида селекторов:**
  - по тегу — `body`, `h1`, `a`, `table.calendar td`;
  - по классу — `.subtitle`, `.news-card`, `.profit`, `.loss`;
  - по идентификатору — `#main-header`;
  - псевдоклассы — `a:hover`, `td:hover`, `:nth-child(even)`, `:last-child`.
- **Использование цвета:** HEX (`#13273F`, `#A9BCE0`, `#4CAF87`), rgba (`rgba(76, 175, 135, 0.40)`), CSS-переменные (`var(--serenity)`), градиенты (`linear-gradient`).
- **Различные виды выравнивания в таблице:**
  - `.col-date` — `text-align: left` (по левому краю);
  - `.col-dir` — `text-align: center` (по центру);
  - `.col-profit` — `text-align: right` (по правому краю).

### Особенности реализации

- **Стиль Liquid Glass (glassmorphism)** — эффект «жидкого стекла» в стиле Apple реализован нативным CSS-свойством `backdrop-filter: blur()` в сочетании с полупрозрачным `rgba`-фоном и тонкой светлой границей. Это позволяет создавать размытие фона позади элементов без использования JS.
- **Цветовая палитра** — благородные оттенки Mystic Navy (`#13273F`), Cherries Jubilee (`#4A1F26`) и Serenity (`#A9BCE0`).
- **Цветовая индикация профита:** прибыльные дни в календаре светятся мягким зелёным, убыточные — благородным бордовым. Эффект свечения достигается через `box-shadow` и `text-shadow`.
- **Адаптивная шапка:** `position: sticky` + `backdrop-filter` — при скролле контент размывается позади меню.
